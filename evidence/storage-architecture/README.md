## 性能诊断

`probe/` 用旧 256 项工作原始终态及全部事件建立新临时库，执行准备和测量生命周期，保留所有原历史。只报告宿主机小样本，不能替代 4 vCPU / 8 GiB 正式负载或声称真实 GPU 加速。初次探测与工程测试、既有 CPU 服务共享宿主机，未停止这些服务。

`profile-development/` 保留一条续租的 cProfile 原始记录，定位到逐基础值 JSON 往返及保存后重复编码；profiler 放大解释器成本，不把其耗时当作无剖析延迟。源代码修补后的探测单独保存，不覆盖首次结果。没有同环境交错基线试验，不宣称统计意义上的加速倍数。

诊断计数 `touched_rows` 表示事务末仍在缓存中的行，不含已删除对象；`entity_rows_written` 包含删除。普通提交仍读取上一条日志，因此初始化、批量导入等巨型提交之后的一次请求会有额外成本。启动审计、迁移和完整导出本来就允许全量读取；未宣称所有操作为常数时间。
