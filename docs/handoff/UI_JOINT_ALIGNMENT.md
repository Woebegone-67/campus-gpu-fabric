## 本轮发现与修正

B 的辅助负载工具原先先创建 TTL=300，再以 TTL=300 续租；冻结逻辑时钟下可能没有实际延长，却因 HTTP 成功计入完成。本轮改为 300→600，断言截止增加 300 秒、身份不变，并在最终读取中再次核对截止持久化；记录增加 `effective-renewal-v2` 与有效续租数。新增反例保证原地续期和最终丢失续期都不能计入完成。

该工具仍与 A 正式负载的资源构成、查询比例和操作顺序不同；不拿它替换正式性能协议，旧结果不重写。

开发检查中的失败也保留：`live-01` 因自动化使用了不完整的复选框名称而中止，未完成部分不计通过；修正定位后在新的空实例执行 `live-02`。第一次 `fixtures` 在切换测试实例时遇到页面服务短暂关闭，后续用稳定实例完整重跑为 `fixtures-02`。这些是检查脚本/环境问题，不藏掉后再声称所有尝试一次通过。
