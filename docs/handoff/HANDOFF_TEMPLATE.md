# 交接回执模板

复制到自己的证据目录，每次提交填一份；不要覆盖失败历史。当前模板不是执行记录。

- 节点 / 责任人 / 接收人 / T0与当前时间：
- 分支 / commit / 构建身份 / 语义与合同版本：
- 本次已实现能力 / 未实现能力：
- 入口、端口、实例ID、数据库与run目录（不含密钥）：
- 变更路径；对方无需修改的接入方式：
- 下一步独立可做的任务：

| 目标ID | MET/NOT_MET/NOT_RUN | 可复制命令/操作 | 预期 | 实际 | 证据路径 |
|---|---|---|---|---|---|
|  | NOT_RUN |  |  | 尚未执行 |  |

失败/偏差：请求ID、epoch/revision、逻辑时刻、attempt/generation、事件片段、复现输入、责任模块、局部修复及复验命令。没有实测不要填MET。

跨边界事项最多三项：明确缺哪个字段/回执/行为、谁修改、兼容方式、影响的验收。涉及主办方答疑时附原始说明及日期；团队暂定语义不能冒充官方答复。

交付/上传单列：文件路径与哈希、实际上传位置及回执；没有上传回执只写本地打包。模拟 / CPU实际执行 / GPU执行分别记录；无GPU证据不可声称GPU已验证。
