# CP0–CP5 验收门槛

T0=两人登记的正式开工时刻；每次约20分钟。节点检查同一终态产品，不到点降标。目标ID与量化判据以蓝图03为唯一来源。每项状态只用MET / NOT_MET / NOT_RUN；设计检查不能替代运行测试。CP0实际机器结果见交付记录；后续节点按真实运行证据验收。

| 门槛 | 时点 | 必须交付并实际核验 |
|---|---|---|
| CP0 | H1 | 官方原件校验；21操作归属映射；contracts及样例；语义配置/状态占用/三角色六区；两份开工单；可运行的项目检查入口。设计就绪与运行能力分账 |
| CP1 | H5 | 正常旅程真实接通、持久重载、32并发争末资源、key冲突/断线重发、clock到期、两阶段部分失败、终态租约去向；换角色操作 |
| CP2 | H10 | 21操作真实记录；ready/failed/timeout/连续回收/无替代/预算耗尽；贡献者隔离；大步clock；首次CPU实际保存停止恢复 |
| CP3 | H16 | 崩溃窗口与旧进程隔离；CPU结果对照；独立模型；前缀一致；五类×五seed与B2/消融；三层保存事实；效果未达据实记录 |
| CP4 | H21 | 换人干净部署；陌生输入；规模/延迟实测；六用户任务/UI检查；图表追到run；构建/模型/视频候选一致 |
| CP5 | H24前 | H23尽量封存；最终回归、源码/锁/原始结果/说明、3–5分钟同构建视频、阅读索引；本地包与实际上传分别记回执 |

执行入口：`make setup` → `make cp0`；开发用 `make api` / `make web`；节点用 `make checkpoint CP=CP1`（替换CP编号）。CP1–CP5未实现的检查必须非零退出并报告NOT_RUN；禁止空测试返回通过。CP0若仅检查材料/类型，报告必须明确范围。

每节点操作：先各自预跑→交换操作者→挑未见输入→保存短回执→只讨论至多三项跨边界阻断。短回执含目标ID、build/输入版本、操作者、命令、预期、实际、证据路径、未决项。失败保留最小历史、归属Owner、局部修复与下一条复验命令。

立即同步只限超卖/越权/跨实例污染、不兼容共享契约、另一方全线阻塞；其他问题由Owner连续修复。接口就绪异步交接；双方不可reset对方库或集成录制实例。GitHub协作以实际邀请/接受状态为准，不把文档列名写成已入组。
