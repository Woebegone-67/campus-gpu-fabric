## B 在自己的机器复现

保留个人修改后，从远端新建本地分支，或者将本分支正常合并进自己的工作分支。不要覆盖整个前端目录或重置已有验收数据。

```sh
git fetch origin
git switch -c joint-ui origin/integration/ui-final-20261115
uv sync --frozen
npm --prefix web ci
uv run python scripts/cp2_joint_session.py start \
  --runtime runtime/b-joint-ui \
  --logical-api-port 18240 --logical-web-port 15240 \
  --cpu-api-port 18241 --cpu-web-port 15241
```

使用 Python 3.12、项目锁定依赖及 Node 22.12–22.x；若上述端口已有其他服务，四个端口一起换为未占用端口。打开 `http://127.0.0.1:15241/` 并导入自己新生成的 `runtime/b-joint-ui/cpu/client-identities.json`。不要借用 A 的凭据。关闭自己实例使用 `uv run python scripts/cp2_joint_session.py stop --runtime runtime/b-joint-ui`。
