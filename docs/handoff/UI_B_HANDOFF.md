依赖为 Python 3.12、uv、Node 22.12+的22.x、npm、make；初始化按仓库 README 的 `make setup`。下面是 B 的建议独立逻辑实例，不会读取 A 的验收数据库：

```sh

FABRIC_INSTANCE=b-ui-v2 FABRIC_MODE=logical_simulation \
FABRIC_DATA_DIR="$PWD/runtime/b-ui-v2" \
FABRIC_AUTH_FILE="$PWD/runtime/b-ui-v2/auth.json" \
FABRIC_INVENTORY_FILE="$PWD/configs/cp1_inventory.json" \
PORT=18096 bash web/dev-local.sh api

# 终端二
FABRIC_API_TARGET=http://127.0.0.1:18096 WEB_PORT=15190 bash web/dev-local.sh web
```
