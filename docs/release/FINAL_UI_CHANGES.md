# 最终界面修改记录

本轮由项目自身完成收尾，不再作为 B 的接管清单。以实际运行代码和最终验证记录为准。

## 删除与收拢

- 删除右上角独立的背景暂停、显示设置和冗余状态栏；账户与低频偏好放在一个账户入口。
- 删除侧栏底部口号、工作台英文眉题、重复页面标题和逐模块解释段落。
- 删除 CPU 参考实例供给整块说明；没有自有设备时不展示无法执行的收回表单。
- 删除普通活动页的实验、策略报告和验收堆叠；移入管理员工具，展开才读取。
- 工作结果不重复解释模拟/真实边界，不给运行中的工作显示空“结果与结算”盒子。实例类型集中在账户菜单，运行范围在阅读手册中说明。
- 删除新建表单中当前实例不会实际执行的镜像/命令编辑器；保留兼容登记值。
- 技术 ID、原始回执、预算与保存点细节可按需展开，主要界面先展示工作状态和操作。

## 流程调整

- 工作必须有名称；成功创建后自动进入该工作。
- 新建默认使用可用的保存点恢复能力，并在结束后归还资源。
- 收起或切换页面后保留新建草稿；账户切换清除旧账户内容。
- 总览的待办和进行中去重，管理员总览读取真实全局计数；空设备列表不占首页区域。
- 工作详情只显示服务允许的动作。恢复、释放等主操作不再埋在一排禁用按钮里。
- 列表默认显示全部状态；无数据时去掉筛选器，无其他页时不显示无用翻页控件。
- 资源和执行技术记录按展开才加载。
- 区分等待资源、已有资源等待启动、收回中、停止确认中和资源已归还。
- 活动缺少名称元数据时使用中性工作编号，避免误标为未命名；合并同一事件的重复状态。

## 防止实际误操作

- 新建和通用动作的同步重复触发只发送一次。
- 请求结果未知时保留同一工作和输入，不能重新提交。
- 失败刷新不会清除未知结果锁；成功读取当前状态后才能重新操作。
- 真实超时返回映射为“运行超时”，完整原因仍保留在技术记录。
- 接续显示基于核验和实际应用事实，下载保留原文件字节。

最终验证的范围、构建和证据见 `FINAL_ACCEPTANCE.md`。本文件说明改了什么，不代替实际测试记录。
